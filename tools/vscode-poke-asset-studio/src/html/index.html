Gen 3 style bible (enforced)

Light: top-left. Highlights upper-left, shadows bottom-right.
Outlines: 1px, color-coded (deep navy / crimson / brown — not pure black). Black only for eyes / deepest crevices. Inner lines lighter than exterior.
Shading: 2–4 cel tones per material (base + 1 hi + 1–2 shade). Dither only fur / sand / rock.
Camera: front = ¾ facing left; back = over-shoulder facing upper-right; OW = high-angle oblique chibi; trainer back = bust facing right.
Hardware: dims must be multiples of 8 · 15 visible + 1 transparent · BGR555 steps of 8 · front/back share one palette · shiny = same indices, hue-rotated, darks kept.

Master palette (shared front/back)

Index 0 = transparent. Front + back + anim frames must reference this identical table. Shiny keeps the same order — only colors change.
When ON (default), the back sprite is re-mapped to the front's master palette with nearest-color matching — guaranteeing the shared-palette rule even though pixels differ.

POKÉMON GBA FORGE · Authentic Game Boy Advance asset pipeline. Every graphic is automatically validated and converted to GBA specifications: 4bpp indexed color, 16-color palettes (index 0 transparent), BGR555 color space, 8×8 tile alignment, shared front/back master palette, and index-matched shiny palette generation with luminance preservation.

AI-generated artwork serves only as a starting sketch. Every imported image is re-quantized, palette-corrected, and rebuilt into production-ready assets suitable for direct ROM integration.
