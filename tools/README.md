# Pokémon Confluence Development Toolchain

This directory contains specialized editors, compilers, conversion pipelines, and IDE extensions for Pokémon Confluence (`pokeconfluence`) and GBA decompilations:

| Tool | Type | Purpose |
| :--- | :--- | :--- |
| **`vscode-poke-asset-studio`** | VSCode Extension | High-performance Asset Gallery, Pixel Inspector, 16-Color Palette Studio, and Sprite Animator for GBA decompilations. |
| **`porymap`** | Native GUI (C++/Qt) | Visual overworld map, event, layout, connection, and wild encounter editor. |
| **`porytiles`** | CLI Compiler | Modern RGBA tileset to GBA 4bpp metatile and palette compiler. |
| **`poryscript`** | DSL Compiler | High-level scripting compiler that generates `.inc` bytecode scripts from `.pory`. |
| **`porypal`** | Palette Utility | Automatic palette assignment and reduction tool. |
| **`poke-migrator-pro`** | Python Toolsuite | 53 specialized CLI tools for maps, tilesets, scripts, and audio migration. |
| **`pokeemerald-ai-bridge`** | VSCode Extension | Intelligent workspace assistant bridge for pokeemerald expansion. |
| **`mgba-agent`** | Headless Harness | Python-controlled headless mGBA emulator test and RAM inspection suite. |
